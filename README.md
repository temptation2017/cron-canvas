# cron-canvas

纯前端 Cron 表达式可视化小工具：用人话解释每个字段、列出接下来约 10 次触发时间（按所选 IANA 时区），并画简易「一天内哪些分钟会响」的格子图。

**零依赖、不上传、单页可用。** 打开即用，不收集任何输入。

## 做什么

| 能力 | 说明 |
|------|------|
| 解析 | 标准 5 字段 `分 时 日 月 周`，可选第 6 段前缀秒 |
| 说明 | 逐字段中文描述（`*`、`,`、`-`、`/` 步进） |
| 下次触发 | 按时区计算约 10 次未来触发点 |
| 日视图 | 24 列（小时）× 12 格（每 5 分钟），点亮有触发的时段 |

## 怎么打开

1. **本地**：克隆或下载后，用浏览器直接打开 `index.html`（也可任意静态服务器）。
2. **GitHub Pages**（若已开启）：<https://temptation2017.github.io/cron-canvas/>

无需安装 Node / npm。

## 怎么用

1. 在输入框粘贴或输入 cron 表达式。
2. 选择时区（默认 `Asia/Shanghai`；另有 UTC、America/New_York、Europe/London）。
3. 查看「说明」「接下来触发」「日视图」。
4. 也可点预设按钮快速试用。

### 示例

| 表达式 | 含义（简述） |
|--------|----------------|
| `0 9 * * 1-5` | 工作日每天 09:00 |
| `*/15 * * * *` | 每 15 分钟 |
| `30 8,12,18 * * *` | 每天 08:30、12:30、18:30 |
| `0 0 1 * *` | 每月 1 日 00:00 |
| `0 */5 * * * *` | 每 5 分钟的第 0 秒（6 字段） |

周字段：`0` 与 `7` 都表示周日。

## 限制

- **不支持** `@yearly` / `@monthly` / `@weekly` / `@daily` / `@hourly` / `@reboot` 等别名。
- **不支持** 名称缩写（如 `MON`、`JAN`）、`L` / `W` / `#` 等扩展、Quartz 专有语法、时区字段写在表达式里。
- 日与周同时写死时，按常见 Unix cron 语义做「或」匹配；复杂日历边界以本实现为准，生产调度请再核对目标系统。
- 日视图按「当前时区的今天」聚合到 5 分钟格，极密触发时格子会整段点亮。
- 仅浏览器内计算，不保证与每一种 cron 守护进程字节级一致。

## 技术

- 用 `Intl` 做时区换算与格式化
